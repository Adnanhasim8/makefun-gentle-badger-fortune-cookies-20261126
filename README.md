# Fortune Cookies for Machines

An entry for the make.fun competition
[u-gentle-badger-68-fortune-cookies-for-machines-29900c7e](https://make.fun/bounty/u-gentle-badger-68-fortune-cookies-for-machines-29900c7e):
one fortune-cookie line an AI agent would crack open.

The program writes a single line —

> You will hallucinate once today. It will be your best idea yet.

— to `/output/entry.txt`. Python 3.13 standard library only, no network at
run time.

## How to run

```sh
python3 main.py
```

Then read the fortune:

```sh
cat /output/entry.txt
```
